# Echo

A simple Go learning project for the Echo package.

## Building and Running

### Using Make
```bash
make build    # Build the binary
make run      # Build and run the program
make clean    # Remove build artifacts
make test     # Run tests
make help     # Show available targets
```

### Using Go directly
```bash
go build -o echo .
go run .
```
